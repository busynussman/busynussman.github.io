Bonsai Ma is a quiet, always-available generative tree for macOS.

Using the window

  • Drag anywhere on the canvas to move the tree.
  • Release it near a display corner to snap it into place.
  • Resize from any edge or corner. The artwork keeps its original proportions.
  • Use Window → Always on Top to choose whether Bonsai Ma stays above other windows.

The daily tree

The first time Bonsai Ma opens each day, the new tree sprouts from spring. The same tree then moves through spring, summer, autumn, and winter each hour. A new deterministic tree begins the next day.
